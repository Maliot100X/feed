# Internal agent context, decisions, and trajectory audit

Audit started October 10, 2026. **In progress; not a claim of exhaustive closure.**

This audit targets the current working tree, including the existing Feed rebrand. Pre-existing edits are preserved. Initial versions of files changed by this audit are saved in `/tmp/feed-agent-audit-baseline`. No production database has been modified. Runtime inspection uses a dedicated Postgres cluster on loopback port 55439, database `feed_agent_audit`, bootstrapped through the real engine (204 NPCs, 60 organizations, 38 perp snapshots).

## Execution paths examined

1. `AutonomousCoordinator` → `MultiStepExecutor` → context/interaction gatherers → multi-step prompt → `callAgentLLM` → provider → normalized decision → direct executors → refreshed next-iteration context.
2. Goal-based `AutonomousPlanningCoordinator` → planning prompt → trading/posting/commenting/DM/batch-response services → provider → direct executors.
3. NPC batch `MarketDecisionEngine` → `MarketContextService` → dashboard + world/event/market/memory context → prompt renderer → engine LLM → decision validation.
4. NPC private game context → market arc → question outcome → natural-language signals.
5. Shared chat snapshots and current messages → autonomous group intel and pending interactions.
6. Engine LLM callback and agent bridge → DAG trace; trajectory runtime logger; context inspector and standalone traced tick.

The source inventory is in `runs/agent-context-audit-2026-10-10/source-inventory.json`. An inventory entry does not mean exhaustive manual review of that file.
